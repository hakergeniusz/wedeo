# `wedeo-codec-hevc-cabac`

- Kind: codec (library)
- FFmpeg reference: `~/Projects/FFmpeg/libavcodec/hevc/cabac.c`
  (plus `libavcodec/cabac.c`, `cabac_functions.h`, `cabac.h`)
- Owner: one subagent, this crate directory only
- Status: implemented

Pure-Rust HEVC CABAC binary arithmetic decoder and syntax-element context
engine. Exposes a reusable `Cabac` struct with public context models
(`states` / `stat_coeff`) and `decode_*` methods for every CABAC-coded HEVC
syntax element, including coefficient coding (last-significant-coefficient,
significance maps, absolute levels, Rice/bypass suffixes, sign hiding),
transform-skip / RDPCM and MVD contexts.

Dequantisation, scaling lists and inverse transforms are intentionally left to
the downstream HEVC DSP crate: `decode_residual_coefficients` yields signed
quantisation levels at raster positions and returns a `ResidualInfo` describing
the flags the caller still needs.

Verification: unit tests use synthetic streams whose expected bins were
generated by an independent Python port of FFmpeg's engine and cross-checked
against a standalone build of the actual FFmpeg C functions. The FATE test
additionally exercises the engine on real HEVC slice data.

Do not put this work unit in another crate. Conformance tests belong in
`tests/fate/tests/fate_codec_hevc_cabac.rs`.
